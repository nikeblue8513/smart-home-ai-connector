# Smart Home AI Connector 0.5.0

HomeCore's outbound Home Assistant bridge with minimal device-data sync, destination-bound pairing, bounded retries, and durable command receipts.

Upgrading from 0.4.x requires a new pairing code and a schema-2 HomeCore relay. Remote control defaults off; enable light control locally only when ready. Locks have a separate permission. This app does not replace the local Smart Home Core Connector interface.

See DOCS.md for configuration and supported commands.
